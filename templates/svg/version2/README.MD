# SVG Assets

The SVG illustrations used in this project are stored in the  `../template/svg/version2/` directory.

These graphics were designed and exported using IA prompts, which was used to create scalable vector artwork for the different vehicle types supported by the card. SVG format was chosen to ensure:

- Sharp rendering at any size
- Low file size and fast loading
- Easy customization of colors and shapes
- Consistent appearance across devices and screen resolutions

The source SVG files and the prompt used to generate them live in this repository. This makes future updates, refinements, and new vehicle models easier to add.
