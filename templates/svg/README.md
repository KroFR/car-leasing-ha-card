# SVG Assets

The SVG illustrations used in this project are stored in the /svg directory.

These graphics were designed and exported using [Figma](https://www.figma.com/), which was used to create scalable vector artwork for the different vehicle types supported by the card. SVG format was chosen to ensure:

- Sharp rendering at any size
- Low file size and fast loading
- Easy customization of colors and shapes
- Consistent appearance across devices and screen resolutions

The source SVG files are maintained in this repository to simplify future updates, refinements, and the addition of new vehicle models.
